# Code of Conduct

AEGIS is built for everyone, including people new to programming. Be kind.

- Be respectful and welcoming; assume good intent.
- Critique code and ideas, never people.
- No harassment, insults, discrimination or sharing others' private information.
- Help newcomers — "good first issue" exists for them.

Problems can be reported privately to the maintainer through the repository's
[security reporting form](https://github.com/gomadanyvickdistelpika/freellmharness/security/advisories/new)
or a direct message on GitHub. The maintainer may remove comments, close issues or block
accounts that break these rules.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
