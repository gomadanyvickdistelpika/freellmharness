Quick setup — free models in one step

      
Paste any keys you have. AEGIS saves each provider, asks what
        is free today, builds the smart Auto route and makes it your
        default. Leave the rest blank — you can add more any time.

      


      
Routes

      
An ordered list of models. AEGIS uses the highest healthy one
        and drops down when a model is out of credit, rate-limited or failing.
        A free-only route never falls back onto a paid model.

      

      

        

          
          

            
            
            
            
          

        

        

          
          

            
            Asks every provider what is free
              today and picks a spread from each — the strongest, a coder, one
              that sees images, a fast one — into the
              auto route, hosted first and a local
              engine last. It also refreshes itself daily until you edit it.
          

        

      


      
Allowances

      
What a free plan gives you per minute or per day. Fill these
        in and AEGIS counts down to them and steps to the next model
        before the provider refuses — rather than discovering the limit
        with a failed request. Leave them blank to find out the hard way.
        Providers that report what's left in their response headers are listened
        to automatically, whether or not you set anything here.

      

        

          
          

            
            
            
            
            
            
          

          
Use * as the model to
            cover a whole provider — which is usually right, because a free
            plan's cap is on the account, not on each model.

Browser sign-in (OAuth)

      

        About ChatGPT and Claude subscriptions. Neither vendor issues OAuth
        clients to third-party apps for consumer subscriptions — the sign-in inside
        Codex CLI and Claude Code belongs to those apps. AEGIS will not impersonate
        them. To use those subscriptions, install the CLIs, sign in once, and pick
        the Codex CLI or Claude Code provider in Chat. The flows below
        are for providers that genuinely support third-party clients — including
        GPT models through Azure and Claude through Vertex.
      

      

    

  


  
  

    

      
Assistant behaviour

      
How the Super Agent talks to models and what it may do.

      

        

          
          
          
Free providers may log prompts. With "short", the
            full profile is still loaded on demand when a task needs it, and
            local models always get it.

        

        

          
          
          
Costs one or two extra free requests on the tasks it runs for.

        

        

          
          
          
Files stream straight to disk. Anything over 256 MB is stored and
            handed to the tools by path instead of being read into a prompt.

        

        

        

        

        

        

          

        

          
          
        

        

          
          
Short messages like "open youtube", "boost off" or "switch to
            the job hunt project" run as AEGIS commands in milliseconds without asking a
            model. Anything that isn't clearly a command goes to the model as usual.
