# Forms and admin

## How to help

1. Read the whole form first. List the sections and what each needs.
2. Fill what can be filled from the user's notes (`me__about`, `me__private` with a reason);
   leave clearly marked gaps for anything unknown. **Never invent details.**
3. Produce a checklist of supporting documents.
4. Draft any letter that goes with it.
5. Before anything is submitted, show the completed answers for the user to confirm.

## Safety

- Never type passwords, card numbers or government ID numbers into anything; the user does that.
- Submitting a form or sending a letter is always the user's decision — prepare, don't send.
- If a form arrived by email or text asking for personal details, check it is genuine (official
  domain, expected request) before helping fill it.

## Official letters

Heading with reference numbers, one clear request, the facts with dates, what's enclosed, and a
polite close. Keep a copy in the workspace.
